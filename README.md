# My Dashboard

A personal **Next.js** dashboard built with the App Router, **Tailwind CSS**, and **TypeScript**.

## Overview

A lightweight dashboard app used for personal data / widgets, deployed on Vercel. It demonstrates modern Next.js patterns including the App Router and server components.

## Features

- Dashboard layout with Tailwind CSS
- App Router with server-side rendering
- Deployed on Vercel

## Tech Stack

Next.js, Tailwind CSS, TypeScript, Vercel.

## Status

Personal project (in use).
